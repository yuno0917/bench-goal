# ベンチプレス伸び計算機

今のベンチプレスのMAXと体重、性別から、何週間で何kg伸びるかを研究データで予測する Web ツールです。公開先は https://yuno-lab.com/bench-goal/ です。

- 性別と体重比（MAX ÷ 体重）から、研究で見られた1週あたりの伸びの幅を出す
- 目標（+◯kg）に届くかを判定し、必要な週数の目安を出す
- 重さと回数からMAXを出す4つの式（Brzycki・Epley・Mayhew・Lombardi）を比べる
- 今のMAXで何kgなら何回できるかを、研究の表（Nuzzo 2024）から出す
- `evidence.html` は、ベンチプレス プログラムメーカーと共通の研究まとめ

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 入力フォーム・予測・判定・計算式・回数の表・よくある質問・免責 |
| `evidence.html` | 根拠にした研究のまとめと計算方法 |
| `tests.html` | ロジックのテスト（ブラウザで開くと結果を表示） |
| `js/bg-data.js` | 研究の数字、伸びの幅、計算式、回数の表 |
| `js/bg-calc.js` | 予測・判定・MAX推定のロジック |
| `js/bg-chart.js` | グラフ（SVG） |
| `js/app.js` | フォーム・描画・保存・共有リンク |

研究の数字や伸びの幅を変えたら `tests.html` を開き、テストがすべて通ることを確認してください。`index.html` と `evidence.html` の表の数字も合わせて直します。
